# Conceptos clave JavaScript

Bullets para repaso de memoria.

## Hoisting

- Elevar variables y funciones para que puedan usarse antes de su declaración. Lo hace el runtime (V8 o Hermes).
- `const` y `let` → ReferenceError (TDZ)
- `var` → `undefined`
- Funciones declaradas con `function` están hoisted completas: las podés invocar en la línea 3 aunque estén declaradas en la línea 100

## Scope

- **Block** — `let` y `const`
- **Function** — `var`
- **Global**

## Context (`this`)

- `this` apunta al objeto que **llamó** a la función
- Si la función es miembro de un objeto, `this` es ese objeto
- En scope global: `this === window`

## Tipos de dato

- Primitivos. Pasan por valor (es lo mismo "por copia"): `string`, `number`, `boolean`, `bigint`, `null`, `undefined`, `symbol`
- Por referencia: arrays, objetos, funciones

## Event loop

- JS es **single-threaded**: una call stack
- Lo asíncrono no es otro thread JS; delega y retoma con el event loop
- Orden: stack síncrona → vaciar **microtasks** (Promises, `queueMicrotask`) → un **macrotask** (`setTimeout`, I/O) → repetir
- Clásico: `console.log('1')`, `setTimeout(…'2')`, `Promise.then(…'3')`, `console.log('4')` → **1, 4, 3, 2**
- Bloquear la stack con CPU pesada congela la UI

## Closure

- Función que **recuerda** el scope léxico donde fue creada, aunque ese scope ya terminó
- En la práctica: la función lleva sus variables a cuestas
- Usos: estado privado, factories, callbacks
- En React: handlers y effects son closures

## Stale Closure

- Callback que captura variables del scope donde se **creó**, no donde se ejecuta
- Si el valor cambió después, el callback sigue viendo el **valor viejo**
- Patrón JS: `setInterval` que cerró sobre `count` cuando se creó el timer
- En React: cada render crea nuevos bindings; un effect con `[]` deja handlers en render #1 → deps del effect, updater funcional (`setState(prev => …)`), refs

## Arrays — métodos clave

- **map** — transforma cada elemento; devuelve **nuevo array** de la misma longitud. `arr.map(x => x * 2)`
- **filter** — devuelve elementos que pasan el predicado; puede ser más corto. `arr.filter(x => x > 0)`
- **reduce** — acumula a un solo valor (número, objeto, array). `arr.reduce((acc, x) => acc + x, 0)`
- **find** — primer elemento que cumple condición, o `undefined`. Para uno solo, preferir sobre `filter()[0]`
- **some** — `true` si **al menos uno** cumple. `arr.some(x => x.id === id)`
- **every** — `true` si **todos** cumplen. Vacío → `true`
- Ninguno muta el array original (salvo que vos mutés dentro del callback)
- Encadenar: `users.filter(u => u.active).map(u => u.name)`
